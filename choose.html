    02Workflow

    Whatever method you choose

    A six-step workflow

    The same process whatever method you choose. Step 6 is what regulators and HTA bodies will ask for.

    1. Define the purpose

      What decision or task will the data support?

    2. Prepare the data

      Clean it, set data types and write down the clinical rules.

    3. Start simple

      Fit a baseline such as a Gaussian copula.

    4. Go complex if needed

      Try a deep model only if the baseline falls short.

    5. Evaluate

      Fidelity, utility and privacy, judged against the purpose.

    6. Document

      Method, settings, checks and limitations.
